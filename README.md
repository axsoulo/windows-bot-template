# A Discord Bot That Reads Chat Inputs and Converts them into Keyboard Inputs

Through the use of the DPP API, I was able to write a bot that reads specific commands and executes them as a virtual keyboard press onto my computer. In class, we used this to play Pokemon as a group from our phones. There is also an implementation to create an ASCII gamepad in a specific channel, as well as logging the inputs into a file and a specific chat. You can find out more about how to recreate this bot yourself through the Discord Developer portal and the DPP API Documentation!
